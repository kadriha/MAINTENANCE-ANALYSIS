# MAINTENANCE-ANALYSIS
🔧 Maintenance Dashboard – Power BI  This is a maintenance and operations dashboard built using Power BI to help track maintenance expenses and fleet usage.
The dashboard is designed using simple and clear visuals so that both technical and non-technical users can easily understand the data and insights.

**What the Dashboard Shows**

Maintenance expenses over time

Which trucks are used the most

Which drivers are used the most

Cost trends and expense patterns

**Tools Used**

Power BI

Excel (Data source)

**Why is this dashboard useful**

Helps management understand where money is being spent

Helps track truck and driver usage

Helps support better maintenance and cost decisions

Makes data easy to understand for everyone

**This dashboard was created to support data-driven decision making in maintenance and logistics operations.**
